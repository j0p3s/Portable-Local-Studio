# Portable Local Studio 1.0.0

- Attach text/code files and PDFs before loading a chat model, or drag and drop them into the composer (20 MB per file). Images require a loaded vision model.
- Search DuckDuckGo from the new Web search workspace without loading a model, or enable Web in chat. Internet access is required.
- Generate video through a local ComfyUI engine: upload an API-format video workflow, choose its positive prompt node, generate, preview, and download saved output.

## Download and run

The ZIP includes application source, platform launch scripts, and the compiled React frontend. It does not include portable Node runtimes, native inference engines, ComfyUI, or model weights. Platform launchers install their dependencies on first run as described in README.md. For a machine with Node 24 already installed, extract the ZIP and run `node scripts/server/serve.cjs` from its root to start the built UI/API.

Video generation additionally requires ComfyUI running locally on port 8188, its model weights/custom nodes, and a working video workflow that saves MP4, WebM, MOV, or GIF output. Set COMFYUI_URL to use another loopback port. The integration does not install video models.

## Validation

Frontend production build and 31 regression/integration tests passed. Browser smoke checks covered document upload and simulated search/video responses. Actual video inference was not validated; live search depends on outbound network access. SHA256SUMS verifies the downloadable ZIP.
